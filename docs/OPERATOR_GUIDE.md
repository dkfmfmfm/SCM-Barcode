# BeyondPack 작업자 1페이지 가이드

## 작업 시작 (매번)

1. 바탕화면 `BeyondPack` 실행
2. 상단 배너가 `최신` 또는 `캐시 사용 중`인지 확인
3. **작업 국가** 선택
4. **작업자** 이름 또는 사번 입력
5. **출고건** 문서번호 입력 — 몇 글자 치면 최근 목록이 뜬다. **목록에서 고른다**
6. 옆의 **`다음 #N`** 확인 — 이어작업인데 `다음 #1`이면 문서번호가 틀린 것이다

## 박스 하나 만들기

1. FNSKU 스캔 → 품목명·품목코드·SKU·국가가 실물과 맞는지 확인
2. **박스당 상품수량** 입력 → `합포 구성에 추가`
3. 합포면 다음 FNSKU도 같은 방법으로 추가
4. **박스수량** 입력 — 빈칸으로 시작하므로 반드시 넣는다
5. **무게 · 가로 · 세로 · 높이** 입력 (박스 1개 기준)
6. `Ctrl+Enter`로 확정
7. 라벨이 박스수량만큼 자동으로 나온다. `#번호` 순서대로 붙인다

숫자칸 옆 `▲/▼`로 값을 올리고 내린다. 길게 누르면 연속으로 변한다.

## 박스번호

**출고건 단위로 이어진다.**

- 같은 출고건이면 프로그램을 껐다 켜도, 다음 날이어도 이어서 매긴다
- 다른 출고건을 넣으면 `#1`부터 다시 시작한다
- `1B` `1b` `1 B`는 같은 출고건이다. `1B-2`는 **다른** 출고건이다
- 출고건이 비어 있으면 확정할 수 없다

같은 출고건을 두 대에서 나눠 작업하면 번호가 겹친다. **한 출고건은 한 작업대에서**.

## 지금까지 얼마나 했는지 보기

박스를 확정하면 **`4. 출고건 작업 현황`** 탭이 자동으로 열리고 내역이 쌓인다.

- 요약: `출고건 1B · 확정 9박스 · 총 중량 95.0 kg · 다음 박스 #10`
- **지난 박스 라벨을 다시 뽑으려면** 그 행을 선택하고 `선택 박스 라벨 재출력`
- 다음 상품을 담기 시작하면 `2. 박스 구성품` 탭으로 자동으로 돌아온다

## 단축키

| 키 | 동작 |
|---|---|
| `Enter` | FNSKU 조회 |
| `Ctrl+Enter` | 박스 확정 |
| `F2` | 상품정보 업데이트 |
| `F4` | 확정 전 입력 초기화 |
| `F8` | 마지막 라벨 재출력 |

## 문제가 생겼을 때

| 증상 | 조치 |
|---|---|
| 미등록 FNSKU | 작업 국가를 확인하고 `F2` 후 다시 스캔. 계속 안 되면 관리자에게 |
| 다른 국가에만 등록됨 | 오류에 나온 등록 국가와 실물을 확인 |
| 사용중지된 상품 | 관리자에게 알린다 (Sheet의 상태값 문제) |
| `상품DB 없음` | 작업을 멈추고 관리자에게 알린다 |
| `캐시 사용 중` | 그대로 작업해도 된다. 관리자에게 알리고 `F2` 한 번 |
| 프린터 오류 | **박스를 다시 등록하지 않는다.** 프린터 복구 후 `F8` 또는 현황 탭에서 재출력 |
| 라벨이 잘리거나 빈 라벨이 나옴 | 작업을 멈추고 관리자에게 알린다 (라벨 크기 설정 문제) |
| `용지를 받아들이지 않아…` 오류 | 프린터 드라이버에 라벨 크기가 없다. 관리자에게 알린다 |

`설정·관리자 도구` 안의 기능은 관리자 지시가 있을 때만 사용한다.

## 작업을 마칠 때

출고건이 끝나면 `출고건 Excel 저장`으로 실적을 저장한다. 그 출고건 전체가 한 파일로 저장된다.
