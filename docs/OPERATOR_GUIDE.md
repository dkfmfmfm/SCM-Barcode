# BeyondPack 작업자 1페이지 가이드

## 기본 작업

1. 바탕화면의 `BeyondPack` 아이콘을 실행한다.
2. 상품DB가 `최신` 또는 `캐시 사용 중`인지 확인한다.
3. `작업 국가`를 선택하고 `출고건` 번호를 스캔·입력한다.
4. 출고건 옆의 `다음 #N`으로 이번에 나올 박스번호를 확인한다.
5. FNSKU를 스캔하고 품목명·품목코드·SKU·국가를 확인한다.
6. 박스당 상품수량을 입력하고 `합포 구성에 추가`를 누른다.
7. 합포이면 다음 FNSKU도 추가한다.
8. 박스수량·무게·가로·세로·높이를 입력한다.
9. `Ctrl+Enter`로 박스를 확정한다. 라벨이 박스수량만큼 자동 출력된다.
10. 라벨의 `#번호`가 박스에 붙인 순서와 맞는지 확인하고 부착한다.

숫자 입력칸 오른쪽의 큰 `▲/▼` 버튼으로 값을 올리고 내릴 수 있다. 길게 누르면 연속으로 변경된다.

## 상품정보 업데이트

- 실행할 때 Google Sheet CSV가 자동으로 다운로드된다.
- 신규 상품이 조회되지 않으면 `F2`를 한 번 누른다.
- 작업자가 CSV나 Excel을 직접 다운로드할 필요는 없다.
- `Excel 비상 업데이트`는 관리자 지시에 따라서만 사용한다.

## 단축키

| 키 | 동작 |
|---|---|
| `F2` | Google Sheet 상품정보 업데이트 |
| `F4` | 현재 입력 초기화 |
| `Ctrl+Enter` | 박스 확정 |
| `F8` | 마지막 라벨 재출력 |

## 박스번호

박스번호는 **출고건 단위**로 이어진다. 같은 출고건이면 프로그램을 껐다 켜도 이어서 매기고, 다른 출고건을 넣으면 `#1`부터 다시 시작한다. 출고건을 비워두면 박스를 확정할 수 없다.

같은 출고건을 여러 작업대가 나눠 작업하면 번호가 겹친다. 한 출고건은 한 작업대에서 처리한다.

## 문제가 생겼을 때

- **미등록 FNSKU:** F2 업데이트 후 다시 스캔하고, 계속 실패하면 관리자에게 전달한다.
- **선택 국가에 상품 없음:** 오류에 표시된 등록 국가를 확인한다.
- **업데이트 실패:** 기존 캐시가 있으면 작업을 계속한다. `상품DB 없음`이면 중단하고 관리자에게 알린다.
- **프린터 오류:** 내용을 다시 입력하지 않고 프린터 복구 후 F8로 재출력한다.
- **라벨이 잘리거나 빈 라벨이 나옴:** 작업을 멈추고 관리자에게 알린다. `라벨 설정`의 크기가 실제 라벨과 다르다.
