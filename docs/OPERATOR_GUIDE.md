# BeyondPack 작업자 1페이지 가이드

## 기본 작업

1. 상단 상품DB 상태가 `최신` 또는 승인된 `캐시 사용 중`인지 확인한다.
2. 상단 `작업 국가`에서 출고 국가를 선택한다.
3. FNSKU를 스캔한다.
4. 품목명·품목코드·SKU·국가명이 실제 상품과 맞는지 확인한다.
5. 박스당 상품수량을 입력하고 `합포 구성에 추가`를 누른다.
6. 합포이면 다음 FNSKU도 같은 방식으로 추가한다.
7. 박스수량, 무게, 가로, 세로, 높이를 실제 측정값으로 입력한다.
8. `Ctrl+Enter`로 박스를 확정한다.
9. 라벨을 출력하고 실제 박스에 부착한다.

한 박스에 구성품이 추가된 뒤에는 국가를 바꿀 수 없다. 다른 국가 작업으로 전환하려면 먼저 박스를 확정하거나 `F4`로 현재 입력을 초기화한다.

## 단축키

| 키 | 동작 |
|---|---|
| `F2` | 상품정보 업데이트 |
| `F4` | 현재 입력 초기화 |
| `Ctrl+Enter` | 박스 확정 |
| `F8` | 마지막 라벨 재출력 |

## 문제가 생겼을 때

- **미등록 FNSKU:** F2로 업데이트한 뒤 다시 스캔한다. 계속 실패하면 오류코드와 FNSKU를 관리자에게 전달한다.
- **선택 국가에 상품 없음:** 오류에 표시되는 등록 국가를 확인하고, 현재 박스가 비어 있을 때 올바른 작업 국가를 선택한다.
- **사용중지 상품:** 임의로 다른 상품을 선택하지 말고 관리자에게 확인한다.
- **업데이트 실패:** 기존 캐시 사용 안내와 마지막 성공시간을 확인한다. 상품DB 없음이면 작업하지 않는다.
- **프린터 오류:** 포장내용을 다시 입력하지 말고 프린터 상태를 복구한 뒤 F8로 재출력한다.
- **강제 종료:** 재실행 후 `미완료 작업 복구`에서 `예`를 선택한다.
