# BeyondPack 작업자 1페이지 가이드

## 기본 작업

1. 바탕화면의 `BeyondPack` 아이콘을 실행한다.
2. 상품DB가 `최신` 또는 `캐시 사용 중`인지 확인한다.
3. `작업 국가`를 선택한다.
4. FNSKU를 스캔하고 품목명·품목코드·SKU·국가명을 확인한다.
5. 박스당 상품수량을 입력하고 `합포 구성에 추가`를 누른다.
6. 합포이면 다음 FNSKU도 추가한다.
7. 박스수량·무게·가로·세로·높이를 입력한다.
8. `Ctrl+Enter`로 박스를 확정하고 라벨을 부착한다.

## 상품정보 업데이트

- 실행할 때 Google Sheet CSV가 자동으로 다운로드된다.
- 신규 상품이 조회되지 않으면 `F2`를 한 번 누른다.
- 작업자가 CSV나 Excel을 직접 다운로드할 필요는 없다.
- `Excel 비상 업데이트`는 관리자 지시에 따라서만 사용한다.

## 단축키

| 키 | 동작 |
|---|---|
| `F2` | Google Sheet 상품정보 업데이트 |
| `F4` | 현재 입력 초기화 |
| `Ctrl+Enter` | 박스 확정 |
| `F8` | 마지막 라벨 재출력 |

## 문제가 생겼을 때

- **미등록 FNSKU:** F2 업데이트 후 다시 스캔하고, 계속 실패하면 관리자에게 전달한다.
- **선택 국가에 상품 없음:** 오류에 표시된 등록 국가를 확인한다.
- **업데이트 실패:** 기존 캐시가 있으면 작업을 계속한다. `상품DB 없음`이면 중단하고 관리자에게 알린다.
- **프린터 오류:** 내용을 다시 입력하지 않고 프린터 복구 후 F8로 재출력한다.
