# BeyondPack · 현장 빠른 안내

상세 절차는 프로그램에서 **F1 · 사용 안내**로 검색하세요.

## 시작

작업자와 출고건을 입력하고 **다음 박스번호**를 확인합니다.
작업 국가는 처음부터 **미국**이 선택되어 있습니다. 다른 국가면 바꿉니다.

한 출고건은 한 PC에서 작업합니다.

## 숫자 입력 — 꼭 알아두기

**칸을 한 번 누르면 들어 있던 값이 통째로 선택됩니다.** 그대로 숫자를 치면 덮어쓰입니다.

| 하려는 것 | 하는 법 |
|---|---|
| 값을 새로 넣기 | 칸을 **한 번** 누르고 숫자를 칩니다 |
| 자릿수 하나만 고치기 | 칸을 **한 번 더** 눌러 커서를 두고 고칩니다 |
| 1씩 올리고 내리기 | 오른쪽 **▲ / ▼** |

친 숫자는 칸 안에 바로 보입니다(`3 BOX`, `10.500 kg / BOX`).
**숫자를 쳤는데 칸이 비어 보이면 작업을 멈추고 관리자에게 알립니다.**

## 포장

1. FNSKU 스캔 → 상품명·코드·국가를 실물과 대조합니다.
2. 박스당 수량 입력 → **Enter**로 구성품을 추가합니다.
3. 박스수량과 박스 1개의 무게·규격을 입력합니다.
4. 하단 합계 확인 → **Ctrl+Enter**로 확정합니다.
5. 라벨 확인 → 박스에 부착합니다. 수동 출력은 **F8**입니다.

구성품 수량은 행을 더블클릭해 변경합니다.
작은 화면에서는 입력 영역을 스크롤합니다. 확정 버튼은 하단에 계속 보입니다.

## 항공·해상 번갈아 작업

**출고건만 바꾸면 됩니다.** 돌아오면 그 출고건의 번호가 이어집니다.

> 구성품을 **담는 도중에** 출고건을 바꾸면 화면이 알려 줍니다.
> 확정할 때 어디에 저장할지 한 번 더 묻습니다. **아니오**면 저장하지 않습니다.

## 정정·취소

**출고 현황**에서 고칠 박스를 선택합니다. **어느 박스든** 됩니다(어제 것도).
**정정** 또는 **확정 취소**를 누르고 사유를 입력합니다. **F4**로 중단하면 원본이 남습니다.

| | 박스번호 | 라벨 |
|---|---|---|
| **정정** | 그대로 | 같은 번호로 다시 뽑아 **덮어 붙입니다** |
| **확정 취소** | 그 박스가 사라짐 | **폐기합니다** |

### 번호가 밀린다는 안내가 뜨면

중간 박스를 취소하거나 박스수량을 바꾸면 **뒤 박스 번호가 당겨집니다.**
몇 박스가 대상인지 먼저 보여 줍니다.

> **상자가 아직 손에 닿을 때만** 진행합니다.
> 이미 실었거나 서류를 넘긴 뒤라면 **진행하지 말고 관리자에게 알립니다.**

진행하면 화면 위에 주황색 재부착 안내가 뜹니다.
**재부착 라벨 출력** → 옛 라벨을 떼고 새 라벨을 붙임 → **재부착 완료**.
이 안내는 완료를 누를 때까지 사라지지 않습니다.

## 문제가 생기면

| 상황 | 조치 |
|---|---|
| 숫자를 쳤는데 칸이 비어 보임 | 작업을 멈추고 관리자에게 알립니다 |
| 미등록 상품 | 국가 확인 → F2 → 재조회 |
| 사용중지·상품정보 변경 | 관리자 확인 후 구성품을 갱신하거나 제거 |
| 프린터 오류 | 다시 확정하지 않고 라벨만 재출력 |
| 백업 실패 | 관리자에게 알리고 백업 위치 확인 |
| 재실행 후 복구 안내 | 실물과 대조하며 미완료 입력 복구 |
| 재부착 안내가 안 사라짐 | 라벨을 다 붙인 뒤 **재부착 완료**를 누릅니다 |

## 마감

실적·실물을 대조하고 **출고건 Excel**로 저장합니다.
완료할 작업은 **작업 완료**를 누릅니다.
백업 상태를 확인한 뒤 창의 닫기 버튼으로 종료합니다.
