# BeyondPack 2.3.0 사용 안내

상품 확인부터 포장 확정, 작업 복구까지.
필요한 절차를 짧고 명확하게 안내합니다.

프로그램에서 **F1 · 사용 안내**를 누르면 이 설명서를 검색할 수 있습니다.
설치폴더의 `docs/USER_MANUAL.html`은 인터넷 없이 열 수 있습니다.

## 01. 빠른 시작

### 매일 작업을 시작할 때

1. BeyondPack을 실행합니다. 상품정보와 백업 상태를 확인합니다.
2. **작업 국가 · 작업자 · 출고건**을 입력합니다.
3. 이어서 작업한다면 최근 출고건을 선택하고 **다음 #번호**를 확인합니다.

**한 출고건은 한 PC에서 작업합니다.** PC 간 포장기록과 박스번호는 자동 공유되지 않습니다.

### 박스를 확정할 때

1. **FNSKU**를 스캔합니다. 직접 입력했다면 Enter를 누릅니다.
2. 상품명·품목코드·SKU·국가를 실물과 대조합니다.
3. **박스당 수량**을 입력하고 Enter 또는 **구성품 추가**를 누릅니다.
4. 합포 상품도 같은 순서로 추가합니다.
5. 박스수량과 무게·가로·세로·높이를 입력합니다.
6. 하단의 **총수량 · 총 중량**을 확인합니다.
7. **박스 확정 · Ctrl+Enter**를 누릅니다.
8. 라벨의 출고건과 박스번호를 확인해 부착합니다.

무게와 규격은 **박스 1개 기준**입니다.
여러 박스를 한 번에 확정하려면 구성품·수량·규격이 모두 같아야 합니다.

자동 출력은 프린터를 지정하고 자동 출력을 켠 경우에 동작합니다.
수동 출력은 **F8 · 마지막 라벨**을 사용합니다.

## 02. 화면과 입력 요령

### 화면 읽기

| 위치 | 확인할 내용 |
|---|---|
| 상단 작업 정보 | 국가, 작업자, 출고건, 다음 박스번호 |
| 상품정보 상태 | 현재 사용 중인 상품정보와 업데이트 결과 |
| 01 상품 확인 | FNSKU 조회와 실물 대조 |
| 02 박스 구성품 | 상품별 박스당 수량 |
| 03 포장 규격 | 박스수량, 박스 1개의 무게와 규격 |
| 출고 현황 | 해당 출고건의 확정 내역과 누적 실적 |
| 하단 합계 | 이번에 확정할 총수량과 총 중량 |

### 빠르고 정확하게 입력하기

- 수량 입력 후 **Enter**로 구성품을 추가합니다. 추가 후에는 스캔 칸으로 돌아갑니다.
- 구성품 행을 더블클릭하거나 **수량 변경**을 눌러 수량을 조정합니다.
- 숫자는 직접 입력하거나 **▲ / ▼**로 조절합니다. 길게 누르면 연속으로 바뀝니다.
- 선택하지 않은 숫자칸은 휠을 굴려도 값이 바뀌지 않습니다.
- 입력이 누락된 상태에서 확정하면 먼저 채울 칸으로 이동합니다.
- 가운데 경계를 끌어 좌우 너비를 조정할 수 있습니다.
- 좁은 화면에서는 입력 영역이 위아래로 배치됩니다. 스크롤해도 하단 합계와 확정 버튼은 계속 표시됩니다.
- 긴 상품명은 어절 단위로 줄바꿈합니다. 열보다 긴 단일 코드는 필요한 경우 나누어 표시합니다.
- 잘린 코드에 마우스를 올리면 전체 값을 확인할 수 있습니다.

### 수량 계산 예시

박스당 상품 A 24개와 상품 B 6개를 담고, 같은 구성으로 8박스를 만듭니다.

- 박스당 수량: **30개**
- 총수량: **240개**
- 박스당 무게가 12.5kg이면 총 중량: **100kg**

## 03. 출고 현황과 라벨

### 박스번호 확인

박스번호는 **출고건 단위**로 이어집니다.
같은 PC에서 같은 출고건을 선택하면 재실행 후에도 번호가 유지됩니다.
다른 출고건은 #1부터 시작합니다.

출고건의 대소문자와 공백은 정규화됩니다.
예를 들어 `1B`, `1b`, `1 B`는 같은 출고건입니다. `1B-2`는 별도 출고건입니다.

### 지난 라벨 다시 출력

1. **출고 현황** 탭을 엽니다.
2. 박스 행을 선택합니다.
3. **라벨 재출력**을 누릅니다.

마지막 확정 박스는 **F8**로 바로 출력할 수 있습니다.
프린터 오류가 나도 저장된 박스를 다시 확정하지 마세요. 연결을 복구한 뒤 라벨만 재출력합니다.

### 실적을 Excel로 저장

**출고건 Excel**을 누르고 파일 위치를 선택합니다.
여러 날에 걸친 기록도 해당 출고건 전체가 한 파일에 담깁니다.
작업 당시의 상품정보, 수량, 규격과 상품DB 버전이 포함됩니다.

## 04. 이전 작업과 이어하기

### 저장된 작업 찾기

1. **이전 작업**을 엽니다.
2. 출고건·작업자·작업ID를 검색합니다.
3. 상태와 기간으로 범위를 좁힙니다. 기간은 **최근 작업일** 기준입니다.
4. 작업을 선택해 확정 박스와 취소·정정 이력을 확인합니다.

**진행 중**인 작업은 **선택 작업 이어하기**로 엽니다.
현재 작성 중인 박스가 있다면 먼저 확정하거나 F4로 초기화합니다.

완료 작업은 조회·Excel 저장·라벨 출력만 가능합니다.
출고건이 없는 구버전 기록도 조회·저장할 수 있지만 이어하기는 지원하지 않습니다.

### 재실행 후 복구

마지막 진행 작업과 마지막 라벨을 자동으로 불러옵니다.
미완료 입력이 있으면 복구 여부를 확인합니다.

- **예:** 구성품·수량·규격·정정 초안을 복구합니다. 실물과 대조한 뒤 확정합니다.
- **아니요:** 미완료 입력만 지웁니다. 기존 확정 기록은 유지합니다.

### 작업 마무리

실적을 확인한 뒤 **작업 완료**를 누릅니다.
완료 처리는 선택한 작업ID에 적용됩니다. 같은 출고건의 다른 작업을 일괄 마감하지 않습니다.
새 작업은 **설정·관리 → 새 작업 시작**에서 시작합니다.

## 05. 정정과 확정 취소

**진행 중인 출고건의 마지막 박스만** 정정·취소할 수 있습니다.
박스번호와 이미 부착한 라벨의 대응을 유지하기 위한 기준입니다.

### 수량이나 규격을 정정할 때

1. **출고 현황**에서 마지막 박스를 선택합니다.
2. **정정**을 누르고 사유를 입력합니다.
3. 불러온 구성품과 포장 규격을 수정합니다.
4. **박스 확정**을 누릅니다.

재확정 전까지 기존 기록은 유지됩니다.
정정을 중단하려면 **F4**를 누릅니다. 원본은 그대로 남습니다.
재확정이 완료되면 원본과 처리자·사유가 이력에 보관됩니다.

### 확정을 취소할 때

마지막 박스를 선택하고 **확정 취소**를 누릅니다.
사유를 입력하면 실적에서 제외되며, 원본은 변경 이력에 남습니다.

### 변경 전 원본 확인

**이전 작업 → 취소·정정 이력**에서 행을 선택하고 **변경 전 원본**을 누릅니다.
원래 구성품·수량·규격과 처리 사유를 확인할 수 있습니다.

정정·취소 후에는 **기존 라벨을 폐기**하고 현재 기록에 맞는 라벨을 부착합니다.
구버전에서 이미 지워져 원본이 남아 있지 않은 기록은 소급 복구되지 않습니다.

## 06. 상품정보와 확정 전 검증

### 상품정보 상태

| 표시 | 의미와 조치 |
|---|---|
| 최신 | 마지막 다운로드와 검증이 완료되었습니다 |
| 저장된 상품정보 | 기존 로컬 상품DB로 작업합니다. 필요하면 F2로 갱신합니다 |
| 업데이트 중 | 다운로드·검증 중입니다. 완료 후 박스를 확정합니다 |
| 상품DB 없음 | 사용할 상품정보가 없습니다. Sheet 설정 또는 Excel 업데이트가 필요합니다 |
| 오류 | 안내 내용을 확인하고 업데이트를 다시 시도합니다 |

프로그램을 시작하면 Google Sheet에서 자동으로 업데이트합니다.
작업 중에는 **F2**로 다시 받을 수 있습니다.
다운로드나 검증이 실패하면 기존 상품DB를 유지합니다.

### 확정 직전 재검증

박스를 확정할 때 구성품을 **현재 활성 로컬 상품DB**와 대조합니다.

- 사용중지·삭제·미등록 상품은 확정을 차단합니다.
- SKU·품목코드·상품명 등이 달라지면 내용을 다시 확인해야 합니다.
- 변경된 상품은 **설정·관리 → 구성품 정보 재확인**으로 갱신합니다. 입력 수량은 유지됩니다.
- 사용할 수 없는 상품은 구성품에서 제거합니다.

박스별 상품DB 버전과 검증 시각이 기록됩니다.
이 검사는 실시간 Google Sheet 조회가 아닙니다. 최신 변경을 반영하려면 먼저 F2로 업데이트합니다.

## 07. 설치와 최초 설정

### 설치

1. 기존 BeyondPack을 종료합니다.
2. **BeyondPack-2.3.0-Windows-x64-Setup.exe**를 실행합니다.
3. 바탕화면 바로가기 생성을 선택하고 설치합니다.
4. 창 제목에서 **BeyondPack 2.3.0**을 확인합니다.

기존 설정과 포장기록은 유지됩니다.
프로그램 안의 **F1 · 사용 안내**와 시작 메뉴의 **BeyondPack 사용 안내**에서 설명서를 엽니다.

### Google Sheet 연결

1. Google Sheet의 **BeyondPack** 탭을 엽니다.
2. 프로그램의 **Sheet 설정**에 전체 주소를 붙여넣습니다.
3. 업데이트 후 상품 건수와 국가 목록을 확인합니다.

### 라벨 설정

1. Windows 프린터 드라이버에 실제 라벨 크기를 등록합니다.
2. **설정·관리 → 라벨 설정**에서 프린터와 가로·세로·여백을 지정합니다.
3. 자동 출력 여부를 선택하고 저장합니다.
4. **테스트 라벨 출력**으로 번호와 잘림 여부를 확인합니다.

기본 규격은 **40 × 25mm**입니다. 실제 사용하는 롤의 크기를 우선합니다.
드라이버가 용지 크기를 지원하지 않으면 드라이버 설정을 먼저 수정합니다.

## 08. 자동 백업과 복원

### 자동으로 보관되는 기록

외부 폴더를 설정하지 않아도 포장기록을 이 PC에 자동 백업합니다.
박스 확정·취소·정정 후 약 20초, 설정한 주기, 정상 종료 시 실행됩니다.
연속 작업 중에는 마지막 변경을 기준으로 예약합니다.

- 최신 전체 사본: `packaging.db`
- 시간별 사본: `packaging-YYYYMMDD-HH.db`
- 기본 위치: `%LOCALAPPDATA%\BeyondPack\data\backups\<PC이름>`

시간별 사본은 보관일수를 적용하되 최신 30개를 유지합니다.

### PC 고장에 대비하기

1. **설정·관리 → 자동 백업 설정**을 엽니다.
2. 외부 복사를 켜고 공유 폴더 또는 별도 드라이브를 지정합니다.
3. 주기와 보관일수를 정한 뒤 저장합니다.
4. 백업 상태와 실제 사본을 확인합니다.

외부 위치에는 PC별 포장기록·일자별 CSV와 상품 마스터 Excel도 보관됩니다.
**로컬 백업 · 외부 미설정**은 로컬 사본만 있다는 뜻입니다. PC 고장까지 보호하지는 않습니다.
백업 실패가 표시되면 관리자가 저장 위치·네트워크·권한을 확인합니다.

### 포장기록 복원

1. 작성 중인 입력을 정리하고 작업자 이름을 입력합니다.
2. **설정·관리 → 포장 백업 복원**을 엽니다.
3. 정상 사본의 `packaging.db` 또는 시간별 DB를 선택합니다.
4. 복원 시점을 확인하고 진행합니다.
5. **이전 작업**에서 출고건과 수량을 대조합니다.

복원은 **현재 PC의 전체 포장기록을 백업 시점으로 되돌립니다.**
여러 PC의 기록을 합치는 기능은 아닙니다.
복원 전 기록은 `data\backups\before-restore`에 별도로 보관합니다.

### 상품 마스터 복원

Google Sheet를 복구하기 어렵다면 외부 백업의 `products` 폴더에서 정상 Excel을 선택합니다.
**설정·관리 → Excel 비상 업데이트**로 적용합니다.
Google Sheet 복구 전에는 F2로 잘못된 내용을 다시 받지 않도록 주의합니다.

## 09. 문제 해결

먼저 아래 조치를 확인하세요. 해결되지 않으면 오류 메시지와 창 제목의 버전을 함께 전달합니다.

| 증상 | 먼저 할 일 |
|---|---|
| 미등록 FNSKU | 작업 국가를 확인하고 F2 업데이트 후 다시 스캔합니다 |
| 사용중지 상품 | 관리자가 Sheet의 Status를 확인합니다. 임의로 다른 상품을 선택하지 않습니다 |
| 상품정보 변경으로 확정 중단 | 구성품 정보 재확인 후 실물과 다시 대조합니다 |
| 수량·규격 누락 | 커서가 이동한 입력칸을 채웁니다 |
| 중간 박스를 정정할 수 없음 | 마지막 박스만 정정할 수 있습니다. 작업 기록과 실물을 관리자에게 확인받습니다 |
| 라벨 출력 실패 | 박스를 다시 확정하지 말고 연결 복구 후 라벨만 재출력합니다 |
| 라벨 잘림·빈 라벨 배출 | 실제 롤과 Windows 드라이버, 라벨 설정의 크기를 맞춥니다 |
| Excel 저장 실패 | 열려 있는 Excel 파일을 닫거나 다른 위치에 저장합니다 |
| 백업 실패 | 관리자가 저장 위치와 연결 상태를 확인한 뒤 지금 백업을 실행합니다 |
| 다른 버전이 실행됨 | 기존 프로그램을 종료하고 설치폴더의 실행파일로 버전을 확인합니다 |

정확한 실행 경로는 `%LOCALAPPDATA%\Programs\BeyondPack\BeyondPack.exe`입니다.

추가 확인이 필요하면 **설정·관리 → 관리자 진단파일 생성**을 사용합니다.
프로그램이 종료될 때는 진행 중인 저장·백업이 끝날 때까지 기다립니다.

## 10. 상품 마스터 관리

### 열 이름

BeyondPack 탭 1행에는 다음 영문 열 이름을 입력합니다.
실제 상품 데이터는 2행부터 작성합니다.

| 열 | 이름 | 기준 |
|---|---|---|
| A | FNSKU | 필수값 |
| B | ItemCode | 품목코드, 필수값 |
| C | SKU | 필수값 |
| D | CountryCode | US·JP 등 국가코드, 필수값 |
| E | ProductName | 상품명, 필수값 |
| F | ProductNameEn | 영문 상품명 |
| G | AmazonAccount | 아마존 계정 |
| H | Status | Published·Active·Y 중 하나일 때 사용 가능 |
| I | SourceModifiedAt | 수정 시각 |
| J | DataVersion | 데이터 버전 |
| K | SchemaVersion | 2 |

**Status가 비어 있으면 사용중지로 처리됩니다.**
신규 시트에는 CountryName이 필요 없습니다. 기존 파일에 남아 있어도 읽을 수 있습니다.

### 수정 후 확인

1. 필수값과 `FNSKU + CountryCode` 중복을 확인합니다.
2. 수정 시각과 데이터 버전을 갱신합니다.
3. 포장 PC에서 F2를 누릅니다.
4. 상품 건수와 대표 상품을 확인합니다.

FNSKU가 같아도 국가가 다르면 국가별로 등록합니다.
상품 수가 이전보다 20% 이상 줄거나 필수값·중복·스키마 검증에 실패하면 기존 DB를 유지합니다.

Excel 비상 업데이트의 시트명은 **BeyondPack**입니다.
기존 **BeyondPack_Master**도 읽을 수 있으며, 둘 다 없으면 첫 시트를 사용합니다.

## 11. 단축키와 마감 점검

| 키 | 동작 |
|---|---|
| F1 | 사용 안내 |
| Ctrl+F | 사용 안내에서 검색 |
| Enter | FNSKU 조회 / 수량 입력 후 구성품 추가 |
| Alt+A | 조회 상품을 구성품에 추가 |
| Ctrl+Enter | 박스 확정 |
| F2 | 상품정보 업데이트 |
| F4 | 확정 전 입력 초기화 / 정정 중단 |
| F8 | 마지막 확정 박스 라벨 출력 |

### 교대·마감 전

- 출고건의 확정 수량과 실물을 대조합니다.
- 필요한 실적을 Excel로 저장합니다.
- 완료할 작업은 **작업 완료**로 마감합니다.
- 백업 상태를 확인합니다.
- 창의 닫기 버튼으로 정상 종료합니다.

입력 초기화는 미확정 입력만 지웁니다. 이미 확정한 박스는 유지됩니다.
