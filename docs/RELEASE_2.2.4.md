# BeyondPack 2.2.4

## 수정 사항

### 박스 라벨이 박스수량만큼 순번대로 나오지 않던 문제 (긴급)

- 박스수량 N개를 확정해도 라벨이 N장 나오지 않고 번호가 이어지지 않던 문제 제거
- 원인: 박스 1개마다 인쇄를 따로 호출해 프린터 드라이버가 각각을 별개 인쇄 작업으로 처리했다. 재현 시험에서 박스 3개에 라벨이 2장만 생성되었다.
- 조치: 박스수량만큼의 라벨을 **하나의 인쇄 작업 안에서 페이지를 넘기며** 출력한다. 박스번호는 저장된 시작번호부터 1씩 증가하며 라벨 1장과 정확히 1:1로 대응한다.
- 박스번호를 `#1`, `#2` 형식으로 크게 인쇄하고 `박스 1 / 8`처럼 전체 장수를 함께 표시한다.

### 라벨이 잘리고 빈 라벨이 함께 배출되던 문제 (긴급)

- 원인: 인쇄 용지 규격을 지정하지 않아 드라이버 기본값인 A4(210×297mm)로 전송되었다. 라벨 프린터는 A4 한 장 분량을 라벨 여러 장에 나누어 배출하므로, 내용이 잘린 라벨 뒤에 빈 라벨이 계속 나왔다.
- 조치: `라벨 설정`에서 지정한 라벨 크기(mm)를 인쇄 용지로 강제한다. 인쇄 대화상자에서 용지가 바뀌어도 라벨 규격을 다시 적용한다.
- 라벨 내용이 라벨 크기를 넘으면 자동으로 축소해 한 장 안에 담는다. 구성품이 6개를 넘으면 남은 건수를 `외 N개 품목`으로 요약해 박스 1개당 라벨 1장을 유지한다.

## 추가 기능

- `라벨 설정`: 라벨 프린터, 라벨 가로·세로(mm), 여백, 확정 시 자동출력을 코드 수정 없이 지정
- `테스트 라벨 출력`: 실제 라벨 1~2장을 뽑아 규격을 확인
- 라벨 프린터를 지정하면 **박스 확정과 동시에 라벨이 자동 출력**된다. `F8` 재출력도 인쇄 대화상자 없이 바로 출력한다.
- 지정한 프린터가 연결되어 있지 않으면 `BP-PRINT-002` 오류로 안내한다.

## 검사 강화

- Windows GUI 자체검사에 라벨 인쇄 회귀시험 추가. 박스 3개를 확정했을 때 라벨이 정확히 3장 생성되는지, 용지가 지정한 라벨 규격인지 실제 인쇄 경로로 검증한다.
- 박스 시작번호·박스수량에서 라벨 번호를 만드는 규칙에 단위시험 추가

## 설치 방법

1. 작업관리자에서 실행 중인 `BeyondPack.exe`를 모두 종료한다.
2. `BeyondPack-2.2.4-Windows-x64-Setup.exe`를 실행해 기존 버전 위에 설치한다.
3. 바탕화면의 BeyondPack을 실행하고 창 제목이 `BeyondPack 2.2.4 · BEYOND EARTH`인지 확인한다.
4. **`라벨 설정`을 눌러 라벨 프린터와 라벨 롤의 실제 크기(mm)를 한 번 지정한다.**
5. `테스트 라벨 출력`으로 규격이 맞는지 확인한다. 내용이 잘리거나 빈 라벨이 나오면 크기를 다시 입력한다.
6. 박스수량을 2 이상으로 넣고 확정해 `#1`, `#2`가 순번대로 나오는지 확인한다.

기존 상품DB, 포장기록, Google Sheet 설정은 유지된다.

## 남은 사항

박스번호는 아직 **프로그램 실행 단위**로 1부터 시작한다. 프로그램을 껐다 켜면 다음 박스가 다시 `#1`이 되므로, 같은 날 여러 번 실행하면 번호가 겹칠 수 있다. 번호 유지 기준(작업일자 단위 / 쉽먼트 단위 / 작업대 단위)을 정한 뒤 다음 버전에서 반영한다. 자세한 내용은 [`docs/REVIEW_2.2.3.md`](REVIEW_2.2.3.md) P0-1을 참고한다.
