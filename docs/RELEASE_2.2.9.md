# BeyondPack 2.2.9

## 1. 작업 현황과 라벨에 FNSKU 표시

작업자가 스캔하는 값이 FNSKU인데 화면과 라벨에는 품목코드가 나와 대조가 되지 않았다. 둘 다 FNSKU로 바꿨다.

- `4. 출고건 작업 현황` 표의 두 번째 열이 **품목코드 → FNSKU**. 컬럼 제목도 `구성품` → `FNSKU`.
- 라벨의 요약 줄도 **품목코드 → FNSKU**.

```text
1B                    1 / 8
#1
X003ABC123 · 15EA · 10.0kg      ← FNSKU, 수량, 박스 무게
```

합포는 양쪽 모두 `합포 N품목`으로 요약된다. 40×25mm 라벨에서 일반적인 10자리 FNSKU는 한 줄에 들어가고, 더 긴 값은 두 줄로 접히되 라벨을 넘지 않는다.

## 2. 마지막 박스 수정·삭제

잘못 확정한 박스를 프로그램 안에서 되돌릴 수 있다. 현황 탭에 버튼 두 개가 추가됐다.

### 수정 — 되돌려서 다시 확정

1. 현황 탭에서 **마지막 행**을 선택하고 `선택 박스 수정`.
2. 사유를 입력한다.
3. 구성품·박스수량·무게·치수가 입력칸으로 돌아오고 `2. 박스 구성품` 탭이 열린다.
4. 고칠 값을 바꾸고 `Ctrl+Enter`로 다시 확정하면 **같은 박스번호**가 붙는다.

되돌린 뒤 다시 확정하는 방식이라 기존 검증(박스수량·무게·치수·구성품)을 그대로 거친다. 구성품 자체를 바꾸거나 합포를 단품으로 고치는 것도 된다.

### 삭제 — 되돌리고 버림

마지막 행을 선택하고 `선택 박스 삭제`, 사유 입력. 박스가 목록에서 사라지고 `다음 #N`이 그 번호로 되돌아간다.

### 마지막 박스만 되돌릴 수 있다

중간 박스를 지우면 이미 출력·부착한 라벨의 번호와 이후 번호가 어긋나 실물과 기록을 맞출 수 없다. 그래서 **출고건의 마지막 박스만** 허용한다. 중간 행을 선택하면 두 버튼이 잠기고 마우스를 올리면 이유가 나온다.

익일 이어작업처럼 작업(job)이 나뉜 경우에도 **출고건 기준의 마지막 박스**면 되돌릴 수 있다.

### 안전장치

- **사유가 필수다.** 비우면 진행되지 않는다.
- 누가·언제·무엇을·왜 되돌렸는지 감사 기록에 남는다. 되돌린 시점의 박스번호·수량·무게·구성품이 통째로 보관된다.
- 작성 중인 구성품이 있으면 수정할 수 없다. 먼저 확정하거나 `F4`로 비운다.
- 되돌린 직후 백업이 예약되어 사본에도 반영된다.

> **이미 출력한 라벨은 반드시 폐기한다.** 프로그램이 되돌려도 인쇄된 종이는 남는다. 화면 안내에도 매번 표시된다.

관리자는 수정·삭제 이력을 다음으로 확인한다.

```sql
SELECT occurred_at, operator_name, action, reason, details_json
FROM audit_events WHERE entity_type = 'BOX_GROUP' AND action IN ('AMEND','DELETE')
ORDER BY id DESC;
```

## 설치 방법

1. 작업관리자에서 실행 중인 `BeyondPack.exe`를 모두 종료한다.
2. `BeyondPack-2.2.9-Windows-x64-Setup.exe`를 실행해 기존 버전 위에 설치한다.
3. 창 제목이 `BeyondPack 2.2.9 · BEYOND EARTH`인지 확인한다.
4. 현황 탭 두 번째 열과 라벨 요약 줄이 FNSKU로 보이는지 확인한다.
5. 테스트 출고건으로 박스를 확정하고 마지막 행 선택 → `선택 박스 수정` → 무게를 고쳐 재확정 → **같은 번호**가 나오는지 확인한다.
6. `선택 박스 삭제` 후 `다음 #N`이 그 번호로 되돌아가는지 확인한다.

기존 상품DB, 포장기록, 출고건 기록, 라벨·백업 설정은 모두 유지된다.

## 남은 사항

중간 박스의 정정은 여전히 프로그램에서 할 수 없다. 이를 허용하려면 박스번호를 재발번하거나 결번을 허용해야 하는데, 둘 다 이미 부착된 라벨과 어긋난다. 라벨에 바코드를 넣어 박스 실물을 스캔으로 대조할 수 있게 되면 그때 다시 검토할 문제다([`docs/REVIEW_2.2.3.md`](REVIEW_2.2.3.md) P0-2).
