# BeyondPack 관리자 운영 가이드

## 1. PC 1대 세팅 (설치 후 한 번)

1. `BeyondPack-<버전>-Windows-x64-Setup.exe`로 설치하고 실행한다. 창 제목의 버전을 확인한다.
2. `Sheet 설정`에 `BeyondPack` 탭이 열린 Google Sheet 주소를 넣는다.
3. 배너에 상품DB 버전·건수·마지막 성공시각이 표시되는지 확인한다.
3-1. `설정·관리자 도구 > 자동 백업 설정`에서 백업 위치를 지정한다. 배너 오른쪽이 `백업 HH:MM`이 되어야 한다.
4. **Windows 프린터 드라이버에 라벨 크기를 등록한다.** `설정 > 프린터 및 스캐너 > 인쇄 기본 설정`에서 `40 x 25mm`를 고르거나 사용자 정의로 추가한다. 이 등록이 없으면 프로그램이 지정한 크기를 드라이버가 거부하고 A4로 인쇄한다.
5. `설정·관리자 도구 > 라벨 설정`에서 프린터와 크기를 지정한다. **안내줄이 초록**이어야 한다. 노랑이면 4번이 덜 된 것이다.
6. `설정·관리자 도구 > 테스트 라벨 출력`으로 확인한다.
7. 정상·미등록·비활성 FNSKU를 각 1건씩 시험 조회한다.
8. 박스수량 3으로 확정해 `#1 #2 #3`이 나오는지, 프로그램을 껐다 켜고 같은 출고건으로 확정해 `#4`부터 이어지는지 확인한다.

## 2. 상품 업데이트

평상시에는 프로그램 시작 시 Google Sheet CSV가 자동으로 내려온다. 작업 중 즉시 반영하려면 `F2`를 누른다. 작업자가 CSV를 따로 받을 일은 없다.

처리 순서는 다음과 같고, 어느 단계에서든 실패하면 **기존 활성 스냅샷을 그대로 사용한다.**

```text
다운로드 → 필수 열 검사 → FNSKU+국가 중복 검사 → 필수값·버전 검사
→ 새 불변 SQLite 스냅샷 생성 → 무결성 검사 → 활성 포인터 원자 전환
```

고정 `products.db`를 덮어쓰지 않으므로 백신·잔존 프로세스의 파일 잠금에도 업데이트가 막히지 않는다.

전체 상품 수가 기존보다 **20% 이상 줄면 차단**한다. Sheet가 잘렸거나 필터가 걸린 채 저장된 경우를 막기 위한 장치다.

Google Sheet 장애 시 `설정·관리자 도구 > Excel 비상 업데이트`로 `.xlsx`를 적용한다. `BeyondPack` 시트를 우선 사용하고 기존 `BeyondPack_Master`도 호환한다. 둘 다 없으면 첫 시트를 쓴다. 검증 규칙은 Google Sheet와 동일하다.

### 자주 나오는 데이터 문제

| 증상 | 원인 | 조치 |
|---|---|---|
| 특정 상품이 `사용중지된 상품입니다` | `Status`가 비어 있다 | `Published`로 채운다 |
| `게시 상태의 상품이 0건입니다` | `Status` 열 전체가 비었다 | 열을 채우거나 열을 삭제한다(없으면 전부 활성으로 처리) |
| `동일 FNSKU+국가가 2건 이상 있습니다` | 중복 행, 또는 `CountryCode`가 빈 행이 2개 이상 | 중복과 빈 국가코드를 정리한다 |
| 국가 목록에 국가가 안 보임 | 그 국가의 활성 상품이 없다 | `Status`와 `CountryCode`를 확인한다 |

## 3. 박스번호와 출고건 운영

박스번호는 **출고건(문서번호) 단위**로 이어지며 날짜·프로그램 실행과 무관하다. 대소문자와 공백은 무시한다.

운영 규칙으로 정해 두어야 할 것:

- **문서번호 표기를 하나로 통일한다.** `1B`와 `1B-2`처럼 표기가 갈리면 번호가 `#1`부터 다시 시작한다. 작업자에게는 자동완성 목록에서 고르도록 교육한다.
- **한 출고건은 한 작업대에서 처리한다.** 박스번호와 작업 현황은 그 PC 안에서만 이어지므로, 두 대에서 나눠 작업하면 번호가 겹친다.

## 4. 실적 보관 — 자동 백업

포장 실적은 `packaging.db`에 그 PC 로컬로만 저장된다. 디스크가 고장나면 복구할 수 없으므로 **PC마다 자동 백업을 반드시 설정한다.**

### 4.1 설정

`설정·관리자 도구 > 자동 백업 설정`

| 항목 | 권장값 | 설명 |
|---|---|---|
| 백업 위치 | 공유 드라이브 경로 | 예: `\\서버\물류\BeyondPack`. 동기화 폴더도 가능하다 |
| 백업 주기 | 10분 | 확정 후 20초 뒤에도 자동 실행되므로 주기는 보조 수단이다 |
| CSV 보관 | 90일 | 일자별 CSV만 정리한다. DB 사본은 지우지 않는다 |

저장하면 즉시 한 번 백업하고 배너 오른쪽이 `백업 HH:MM`으로 바뀐다. 이 표시가 `백업 미설정`이면 그 PC는 보호되지 않는 상태다.

### 4.2 저장되는 파일

```text
<백업 위치>\<PC이름>\packaging.db              포장기록 전체 사본
<백업 위치>\<PC이름>\packing-YYYYMMDD.csv      그날 확정한 박스 실적
```

PC 이름으로 폴더가 갈리므로 여러 작업대가 같은 위치를 공유해도 안전하다. PC 이름이 한글이어도 그대로 쓴다.

### 4.3 복구 절차

1. 새 PC에 같은 버전의 BeyondPack을 설치하고 한 번 실행한 뒤 종료한다.
2. 백업 위치의 `<PC이름>\packaging.db`를 새 PC의 `%LOCALAPPDATA%\BeyondPack\data\packaging.db`로 덮어쓴다.
3. 실행해서 해당 출고건을 입력하고 `4. 출고건 작업 현황`에 지난 박스가 보이는지, `다음 #N`이 이어지는지 확인한다.

### 4.4 운영 규칙

- 자동 백업이 있어도 **출고건 종료 시 `출고건 Excel 저장`**은 계속 권장한다. 정산·공유용 서식이 필요한 경우가 있다.
- 배너에 `백업 실패`가 반복되면 네트워크 경로 권한과 공유 폴더 상태를 점검한다. 실패해도 포장 작업은 멈추지 않으므로 작업자에게는 "계속 작업하고 관리자에게 알린다"로 교육한다.

## 4.5 수정·삭제 이력

작업자가 마지막 박스를 수정하거나 삭제하면 사유와 함께 `audit_events`에 기록된다. 되돌린 시점의 박스번호·수량·무게·구성품이 통째로 남으므로 사후 확인이 가능하다.

```sql
SELECT occurred_at, operator_name, action, reason, details_json
FROM audit_events WHERE entity_type = 'BOX_GROUP' AND action IN ('AMEND','DELETE')
ORDER BY id DESC;
```

되돌리기는 **출고건의 마지막 박스만** 허용한다. 중간 박스를 지우면 이미 출력·부착된 라벨의 번호와 이후 번호가 어긋나기 때문이다. 중간 박스를 정정해야 하는 상황이 반복되면 작업 절차를 점검한다.

## 5. 데이터 파일

| 파일 | 용도 |
|---|---|
| `config.json` | Sheet 주소, 라벨 설정, 백업 설정, 제한값 |
| `products.current.json` | 현재·직전 상품 스냅샷 포인터 |
| `products.snapshot.*.db` | 검증 통과한 상품 캐시(현재·직전) |
| `products.db`, `products.previous.db` | 업그레이드 호환용 기존 캐시 |
| `packaging.db` | 출고건·박스·구성품·감사·임시저장 |
| `sync-status.json` | 마지막 업데이트 결과 |
| `logs\startup.log` | 시작·오류 기록 |

기본 위치는 `%LOCALAPPDATA%\BeyondPack`이다. 프로그램 업데이트·제거에도 유지된다.

오래된 상품DB는 경고만 하고 작업을 막지 않는다. 캐시가 한 건도 없을 때만 작업을 차단한다.

## 6. 진단과 지원 요청

`설정·관리자 도구 > 관리자 진단파일 생성`이 바탕화면에 ZIP을 만든다. 앱 버전, OS, 상품DB 상태, 파일 목록, DB 무결성 결과, 마지막 동기화 결과가 들어간다. **상품 원문과 포장 원문은 포함하지 않는다.**

문의 시 함께 전달할 것: 진단 ZIP, 화면의 오류 코드(`BP-xxx-nnn`), 재현 절차.

## 7. 배포 전 점검

설치 직후 현장 점검은 [현장 도입 점검표](FIELD_CHECKLIST.md)를 인쇄해 항목별로 진행한다. A~E를 통과해야 그 PC로 실작업을 시작하고, 1일 파일럿까지 통과해야 나머지 작업대로 확대한다.

아래는 그 요약이다.
