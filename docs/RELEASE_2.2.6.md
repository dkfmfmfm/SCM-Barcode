# BeyondPack 2.2.6

## 라벨 용지 지정이 조용히 실패하던 문제 (긴급)

2.2.5에서 라벨 크기를 프린터에 지정하도록 바꿨지만, **지정 성공 여부를 확인하지 않았다.**

Windows 프린터 드라이버에 해당 크기의 사용자 정의 용지가 등록되어 있지 않으면 크기 지정이 실패하고 기본값(대개 A4)이 그대로 남는다. 이때 프로그램은 실패를 알지 못한 채 A4 기준으로 라벨을 그렸고, 결과적으로

- A4 한 장 분량이 라벨 롤 여러 장에 나뉘어 배출되고
- 내용이 잘린 라벨 뒤로 빈 라벨이 계속 나오며
- 인쇄영역이 A4로 잡히는 바람에 소형 라벨용 압축 배치 대신 **표 배치**가 선택되어 `#1` 대신 품목코드·SKU 표가 인쇄되었다.

### 조치

- 용지 지정 후 **실제로 적용된 크기를 확인**한다. 설정한 라벨 크기와 다르면 인쇄를 중단하고 원인과 해결 방법을 안내한다.

  > 라벨 프린터가 40×25mm 용지를 받아들이지 않아 210×297mm로 인쇄됩니다. 이대로 출력하면 라벨이 잘리고 빈 라벨이 함께 배출되므로 중단했습니다. Windows [설정 > 프린터 및 스캐너 > 해당 프린터 > 인쇄 기본 설정]에서 40×25mm 사용자 정의 용지를 등록한 뒤 다시 출력하세요. `[BP-PRINT-004]`

- 용지 지정을 한 번만 시도하지 않고 **정확히 일치 → 근사 일치 → 용지·여백 분리 지정** 순으로 재시도한다.
- 압축 배치와 표 배치를 **설정한 라벨 크기**로 결정한다. 프린터가 보고하는 인쇄영역으로 판단하면 용지 지정이 밀렸을 때 배치까지 함께 틀어진다.
- `라벨 설정` 화면에서 선택한 프린터에 이 크기가 등록되어 있는지 **저장 전에 미리 표시**한다. 없으면 드라이버에 등록된 크기 목록과 함께 등록 방법을 안내한다.
- 설정을 저장할 때도 같은 검사를 수행해, 현장 작업 중이 아니라 설정 단계에서 문제를 발견하도록 했다.

## 라벨 프린터 용지 등록 방법 (설치 후 한 번)

1. Windows `설정 > Bluetooth 및 장치 > 프린터 및 스캐너`에서 라벨 프린터를 연다.
2. `인쇄 기본 설정`(또는 `프린터 속성 > 기본 설정`)을 연다.
3. 용지 크기 목록에서 `40 x 25mm`를 고른다. 없으면 `사용자 정의` 또는 `New`로 폭 40mm, 높이 25mm를 추가한다.
4. 확인 후 BeyondPack에서 `라벨 설정`을 열어 초록색 안내(`이 프린터에 40×25mm 용지가 등록되어 있습니다`)를 확인한다.
5. `테스트 라벨 출력`으로 `#1`, `#2` 두 장이 잘리지 않고 나오는지 확인한다.

Zebra·Godex·TSC·Bixolon 등 대부분의 라벨 프린터는 이 등록을 한 번 해두어야 응용 프로그램이 지정한 크기를 받아들인다.

## 설치 방법

1. 작업관리자에서 실행 중인 `BeyondPack.exe`를 모두 종료한다.
2. `BeyondPack-2.2.6-Windows-x64-Setup.exe`를 실행해 기존 버전 위에 설치한다.
3. 창 제목이 `BeyondPack 2.2.6 · BEYOND EARTH`인지 확인한다.
4. 위의 용지 등록 절차를 수행한다.
5. `라벨 설정` → `테스트 라벨 출력` → 출고건 입력 후 박스수량 3으로 확정해 `#1`, `#2`, `#3`을 확인한다.

기존 상품DB, 포장기록, 출고건 기록, Google Sheet 설정은 유지된다.
