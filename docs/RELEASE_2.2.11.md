# BeyondPack 2.2.11

## 라벨 출력 후 커서가 FNSKU 칸으로 돌아온다

현장 요청이다. 박스를 확정해 라벨이 나온 뒤 다음 상품을 스캔하려면 FNSKU 입력칸을 마우스로 다시 눌러야 했다. 이제 인쇄가 끝나면 커서가 알아서 FNSKU 칸으로 돌아온다.

### 어디가 달라졌나

박스 확정(`Ctrl+Enter`)은 원래도 커서를 되돌리고 있었지만, 라벨을 인쇄하면 프린터 드라이버 창과 스풀러 알림이 잠깐 앞으로 나왔다 사라지면서 커서를 가져갔다. 그 일이 프로그램이 커서를 옮긴 **뒤에** 일어나서 결과적으로 커서가 사라진 것처럼 보였다. 이제 인쇄가 정리된 뒤에 한 번 더 확인해서 되돌린다.

되돌리지 않던 경로도 함께 고쳤다.

| 동작 | 이전 | 지금 |
|---|---|---|
| 박스 확정 → 자동 출력 | 인쇄가 커서를 가져가면 그대로 | **FNSKU 칸** |
| `F8` 마지막 라벨 재출력 | 누른 자리에 그대로 | **FNSKU 칸** |
| 현황 탭에서 지난 박스 재출력 | **현황 표**에 남음 | **FNSKU 칸** |
| 테스트 라벨 출력 | 누른 자리에 그대로 | **FNSKU 칸** |

현황 탭 재출력이 특히 불편했다. 표에서 행을 골라야 하니 커서가 항상 표에 가 있었고, 재출력할 때마다 FNSKU 칸을 다시 눌러야 했다.

### 작업자가 옮긴 커서는 뺏지 않는다

인쇄 직후 작업자가 스스로 박스수량이나 무게 칸으로 옮겼다면 그대로 둔다. 프로그램이 커서를 되돌리기 전에 지금 어디에 있는지 먼저 보고, 입력칸 중 하나에 있으면 건드리지 않는다. 되돌리는 건 커서가 표나 버튼처럼 스캔을 받을 수 없는 곳에 있을 때뿐이다.

FNSKU 칸으로 돌아올 때는 기존 내용이 선택된 상태가 되므로, 값이 남아 있어도 바로 스캔하면 덮어쓰인다.

## 설치 방법

1. 작업관리자에서 실행 중인 `BeyondPack.exe`를 모두 종료한다.
2. `BeyondPack-2.2.11-Windows-x64-Setup.exe`를 실행해 기존 버전 위에 설치한다.
3. 창 제목이 `BeyondPack 2.2.11 · BEYOND EARTH`인지 확인한다.
4. 박스를 확정해 라벨을 뽑은 뒤, **마우스를 대지 않고** 바로 다음 상품을 스캔해 본다. 조회가 되면 정상이다.
5. 현황 탭에서 지난 박스를 골라 재출력한 뒤에도 바로 스캔되는지 확인한다.

기존 상품DB, 포장기록, 출고건 기록, 라벨·백업 설정은 모두 유지된다.

## 남은 사항

프린터 드라이버가 인쇄 창을 **계속 띄워 두는** 설정이면(일부 드라이버의 "인쇄 상태 표시" 옵션) 그 창이 화면 앞을 차지하는 동안은 스캔이 그쪽으로 들어간다. 프로그램이 남의 창을 강제로 내리지는 않는다. 이 경우 드라이버 설정에서 인쇄 상태 창을 끄는 것이 맞다.
