# BeyondPack 2.3.2

현장 건의 세 건과, 그 과정에서 찾은 화면 결함 두 건.

## 1. 숫자가 화면에 **보이지 않던** 문제 — 가장 중요

박스수량·무게·가로·세로·높이 칸에 숫자를 쳐도 **화면에 아무것도 나타나지 않았습니다.** 값은 들어가 있었지만 글자가 보이지 않았습니다.

스타일을 입힌 입력칸에서 Qt 기본 증감 단추를 끄면, Qt가 글자를 넣을 자리를 1픽셀로 줄여 버리는 문제였습니다. 화면 오른쪽의 큰 `▲/▼`는 따로 만든 단추라 그동안 눈치채기 어려웠습니다.

**이것이 2번 문제가 늦게 발견된 이유이기도 합니다.** 친 숫자가 안 보이니 잘못 들어간 것을 라벨이 나온 뒤에야 알았습니다.

```text
이전:  박스수량 [                    ]   ← 3을 쳐도 빈칸
지금:  박스수량 [             3 BOX  ]
       무게     [   10.500 kg / BOX  ]
       가로     [          40.00 cm  ]
```

## 2. 박스수량 `12`가 `21`로 들어가던 문제

빈칸이나 `0`이 있는 칸을 **마우스로 누른 직후 곧바로** 숫자를 치면 자리가 뒤집혔습니다.

2.3.1에서 한 번 손봤지만, 그때 쓴 방식이 "잠시 뒤에 기존 값을 선택"하는 것이라 **빠르게 치면 선택보다 글자가 먼저 들어가** 여전히 뒤집혔습니다. 이제 첫 글자가 들어오는 순간에 확실히 덮어쓰도록 바꿨습니다.

| 입력 | 이전 | 지금 |
|---|---|---|
| 박스수량 빈칸에 `12` | `21` | `12` |
| 박스수량 빈칸에 `105` | `051` | `105` |
| 무게 `0.000`에 `12.5` | `120.000` | `12.5` |
| 무게 `9.5`를 `11`로 | `119.500` | `11` |

숫자 하나만 고치고 싶을 때는 **한 번 더 누르면** 그 자리에 커서가 갑니다. 첫 번째 누름만 전체 선택입니다.

> **기존 실적 점검을 권합니다.** 무게가 열 배로 들어간 건이 남아 있을 수 있습니다.
> `출고건 Excel 저장` → 무게 열 내림차순 정렬 → 비정상적으로 큰 값 확인.

## 3. 작업 국가가 처음부터 **미국**으로 선택됩니다

매번 국가를 고르지 않아도 됩니다. 상품DB에 미국이 없으면 예전처럼 `국가 선택`으로 둡니다.

다른 국가를 기본으로 하려면 관리자가 `config.json`의 `default_country_code`를 바꿉니다.

## 4. 항공·해상을 오가며 작업할 수 있습니다

출고건만 바꾸면 됩니다. `새 작업 시작`을 따로 누를 필요가 없습니다.

**이전**: 항공으로 작업하다 해상으로 갔다가 돌아오면 같은 출고건인데도 **작업이 새로 생겨** 이력이 쪼개졌습니다.

**지금**: 돌아온 출고건에 진행 중인 작업이 있으면 그대로 이어집니다. 박스번호도 그 출고건 기준으로 계속 이어집니다.

```text
항공-1 작업 → 해상-1 작업 → 항공-1 복귀
  항공-1 : #1~#2, #3~#4   (작업 1개)
  해상-1 : #1~#2          (작업 1개)
```

### 담던 구성품이 다른 출고건으로 넘어가지 않습니다

구성품을 담는 **도중에** 출고건을 바꾸면 이전에는 조용히 그쪽으로 저장됐습니다. 항공 물건이 해상 실적에 섞일 수 있었습니다.

이제 두 번 알려 줍니다.

1. 출고건을 바꾸는 즉시 — `담고 있는 구성품은 '항공-1' 작업에서 시작했습니다. 이대로 확정하면 '해상-1'에 저장됩니다.`
2. 확정할 때 — 어디에 저장할지 한 번 더 확인합니다. **아니오**를 누르면 저장하지 않고 구성품도 그대로 남습니다.

## 5. 종료할 때 간헐적으로 죽던 문제

프로그램 자체 검사가 끝난 뒤 정리 순서 때문에 간헐적으로 비정상 종료했습니다(12회 중 9회). 창을 확실히 거둔 뒤 끝내도록 고쳐 12회 중 0회가 됐습니다.

## 설치 방법

1. 작업관리자에서 실행 중인 `BeyondPack.exe`를 모두 종료합니다.
2. `BeyondPack-2.3.2-Windows-x64-Setup.exe`로 기존 버전 위에 설치합니다.
3. 창 제목이 `BeyondPack 2.3.2 · BEYOND EARTH`인지 확인합니다.
4. **박스수량 칸에 숫자가 보이는지** 확인합니다. 이게 가장 중요합니다.
5. 칸을 마우스로 누르고 **바로** `12`를 쳐서 `12`로 들어가는지 확인합니다.
6. 작업 국가가 처음부터 `미국 (US)`인지 확인합니다.
7. 항공 출고건으로 박스를 확정하고, 해상 출고건으로 바꿔 확정한 뒤, 다시 항공으로 돌아와 번호가 이어지는지 확인합니다.

기존 상품DB, 포장기록, 출고건 기록, 라벨·백업 설정은 모두 유지됩니다.

## 남은 사항

작업자 대부분이 50대 이상이라는 점을 반영해 화면 글자 크기와 대비를 손보는 일은 아직 하지 않았습니다. 현재 기준 글자는 13px, 보조 설명은 12px입니다. 레이아웃을 함께 조정해야 하므로 별도로 진행하는 것이 안전합니다.
