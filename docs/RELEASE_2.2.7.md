# BeyondPack 2.2.7

현장 건의사항 세 건을 반영했다.

## 1. 출고건 작업 현황을 화면에서 누적 확인

작업 화면 왼쪽 아래가 `2. 박스 구성품`과 `4. 출고건 작업 현황` 두 탭으로 나뉜다.

- 박스를 확정할 때마다 그 내역이 **출고건 현황 탭에 누적**되고 화면이 자동으로 그 탭으로 전환된다.
- 표시 항목: 박스번호(`#1~#3`), 구성품, EA/BOX, 무게, 규격, 확정시각(현장 시간)
- 표 위에 요약이 나온다: `출고건 1B · 확정 9박스 · 총 중량 95.0 kg · 다음 박스 #10`
- 탭 제목에도 건수가 표시되어(`4. 출고건 작업 현황 (9박스)`) 탭을 열지 않아도 진행량을 알 수 있다.
- 다음 상품을 구성품에 추가하면 자동으로 `박스 구성품` 탭으로 돌아온다.
- **지난 박스도 재출력할 수 있다.** 현황 표에서 행을 고르고 `선택 박스 라벨 재출력`을 누른다. 이전에는 마지막에 확정한 박스만 재출력할 수 있었다.

프로그램을 껐다 켜도 같은 출고건을 입력하면 지난 작업 내역이 그대로 다시 표시된다.

## 2. 박스수량 미입력을 빈칸으로 표시

- 박스수량 칸의 기본값 `1 BOX`를 **빈칸**으로 바꿨다. `1`은 그 자체가 올바른 값이어서 작업자가 수량을 입력했는지 화면으로 구분할 수 없었다.
- 빈칸 상태로 확정하면 `박스수량은(는) 1 이상이어야 합니다`로 막힌다.
- 박스를 확정하거나 `F4`로 초기화하면 다시 빈칸이 된다.

무게·가로·세로·높이는 기본값이 `0`이고 0은 애초에 확정할 수 없는 값이라 미입력임이 이미 드러나므로 그대로 두었다.

## 3. 익일 이어작업 시 박스번호 연속

박스번호를 출고건 단위로 잇는 기능은 2.2.5에 이미 들어갔고 정상 동작한다. 같은 문서번호를 입력하면 대소문자와 공백이 달라도(`1B`, `1b`, `1 B`) 마지막 박스 다음 번호부터 이어진다.

다만 문서번호를 매번 다시 타이핑하다 **한 글자라도 달라지면**(`1B` → `1B-2`) 프로그램은 다른 출고건으로 보고 `#1`부터 시작한다. 이를 막기 위해:

- 출고건 칸에 **최근 사용한 출고건 자동완성**을 넣었다. 몇 글자만 입력하면 목록이 뜨고 고르면 된다.
- 출고건을 입력하는 즉시 옆의 `다음 #N`과 현황 표가 그 출고건 기준으로 갱신된다. 이어작업인데 `다음 #1`이 뜨면 문서번호가 다르다는 뜻이다.

## 함께 바뀐 것

- **Excel 저장이 출고건 단위**가 됐다. 버튼 이름도 `출고건 Excel 저장`으로 바꿨다. 한 출고건이 여러 날·여러 실행으로 나뉘어도 실적이 한 파일에 모두 담긴다. 이전에는 현재 실행분만 저장되어 이어작업의 앞부분이 빠졌다.
- 포장실적 Excel 첫 열은 `출고건`이다.
- `라벨 설정`, `테스트 라벨 출력`, `Excel 비상 업데이트`, `관리자 진단파일 생성`을 **`설정·관리자 도구`** 버튼 하나로 모았다. 작업 중 오조작을 줄이고 작업 화면의 세로 공간을 확보했다.
- 상품 정보 표시를 2줄로 압축하고 머리글 폭을 줄여, 1120×760 최소 창에서도 입력칸이 겹치지 않는다.

## 설치 방법

1. 작업관리자에서 실행 중인 `BeyondPack.exe`를 모두 종료한다.
2. `BeyondPack-2.2.7-Windows-x64-Setup.exe`를 실행해 기존 버전 위에 설치한다.
3. 창 제목이 `BeyondPack 2.2.7 · BEYOND EARTH`인지 확인한다.
4. 출고건을 입력하고 `4. 출고건 작업 현황` 탭에 지난 작업이 보이는지 확인한다.
5. 박스수량 칸이 빈칸으로 시작하는지 확인한다.

기존 상품DB, 포장기록, 출고건 기록, 라벨 설정은 모두 유지된다.

## 남은 사항

박스번호와 작업 현황은 **작업 PC 안에서만** 이어진다. 같은 출고건을 여러 작업대가 나눠 작업하면 번호가 겹치고 현황도 따로 보인다. 중앙 발번·수집 서비스가 필요하며 [`docs/REVIEW_2.2.3.md`](REVIEW_2.2.3.md) P0-4, P2-3에 정리되어 있다.
